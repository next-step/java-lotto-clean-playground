# 🎰 로또

이 프로젝트는 사용자가 입력한 금액에 따라 로또 번호를 자동으로 생성해주는 프로그램입니다. 
사용자가 지난 주 당첨 번호를 입력하면, 구매한 로또 번호와 당첨 번호를 비교합니다.
그 결과로 몇 개의 번호가 일치하는지와 그에 대한 통계 정보를 출력합니다.

## 🚀 기능

- 구매 금액에 따라 로또 번호 자동 생성
- 당첨 번호 입력 및 일치 여부 확인
- 통계 출력 (당첨 통계, 수익률 등)

## 💡 사용법

1. 프로그램을 실행하면, 사용자는 구매 금액을 입력해야 합니다.
2. 구매 개수와 자동으로 생성된 로또 번호를 볼 수 있습니다.
3. 그 후, 지난 주 당첨 번호를 입력합니다.
4. 당첨 통계와 수익률을 출력합니다.

```

14000
```
