# 로또 미션

## 기능
- 로또 구입 금액 입력: 1,000원 단위의 로또 구입 금액을 입력받는다.
- 로또 발급: 구입 금액에 해당하는 개수만큼의 로또를 자동 발급한다.
- 번호 생성: 각 로또는 1~45 사이의 중복되지 않는 6개의 번호를 무작위로 생성한다.
- 로또 번호 출력: 발급된 모든 로또의 번호를 오름차순으로 정렬하여 출력한다. 
- 당첨 번호 입력: 지난 주 당첨 번호 6개를 쉼표(,)로 구분하여 입력받는다. 
- 당첨 통계: 구매한 로또를 당첨 번호와 비교하여 등수별 당첨 개수를 계산한다. 
- 수익률 계산 및 최종 결과 발표: 당첨 통계를 바탕으로 총 수익률을 계산하고, 당첨 내역과 함께 최종 결과를 발표한다.

## 조건
- 모든 원시 값과 문자열을 포장한다.
- 일급 컬렉션을 쓴다.
- indent(인덴트, 들여쓰기) depth를 2를 넘지 않도록 구현한다.
-  3항 연산자를 쓰지 않는다.
-  else 예약어를 쓰지 않는다.
-  배열 대신 컬렉션을 사용한다.
-  줄여 쓰지 않는다(축약 금지).
-  함수(또는 메서드)의 길이가 10라인을 넘어가지 않도록 구현한다.
-  함수(또는 메서드)가 한 가지 일만 하도록 최대한 작게 만들어라.

## 프로젝트 구조
- model
    * LottoNumber.java: 로또 번호 하나를 나타내는 객체.
    * Lotto.java: 로또 한 장(6개의 LottoNumber)을 표현하는 객체. 번호 개수 및 중복 유효성을 검증.
    * Lottos.java: 구매한 로또 목록(List<Lotto>)을 관리하는 일급 컬렉션. 당첨 결과 계산을 책임짐.
    * WinningNumbers.java: 당첨 번호를 표현하는 객체. 유효성을 검증하고 번호 포함 여부를 확인.
    * Money.java: 구입 금액을 표현하는 객체.
    * Rank.java: 당첨 등수, 일치 개수, 상금을 관리하는 enum.
    * LottoGenerator.java: 로또 번호를 생성하는 클래스.

- controller
  * LottoController.java: 게임의 전체적인 흐름을 제어하며 Model과 View를 중재.

- view
  * InputView.java: 사용자의 입력을 받는 역할.
  * OutputView.java: 게임의 모든 결과 및 메시지를 출력하는 역할.

- main
    * LottoMain.java: 프로그램의 시작점(main 메서드)을 포함하는 클래스.
