## 🚀 1단계 - 로또 자동 구매
로또 구입 금액을 입력하면 구입 금액에 해당하는 로또를 발급해야 한다.


### 🤔 고민한 내용
- 로또 객체를 생성할때, 어떠한 속성을 가지고 있어야 할지 생각을 해보았습니다.
  로또에서 중요한 것은 로또 번호를 자동생성하는것(1단계 주요**),로또 번호를 출력하는 것,몇개의 번호가 맞는지
  맞추는 것이 중요하다고 생각되어서 그것을 위주로 구현했습니다.


- 또한 여러개의 로또 객체를 받기 때문에, 일급 컬렉션이 반드시 필요하다고 느껴져서, 로또tickets를 구현하였
  습니다.

## 🚀 2단계 - 로또 당첨
로또 당첨 번호를 받아 일치한 번호 수에 따라 당첨 결과를 보여준다..


### 🤔 고민한 내용
- 당첨 통계를 내는 부분에서 3,4,5,6개 일치한 것들을 각각 구해야되었기 때문에 key값에 맞는 value 값을 가져야한다고
  생각하여서, Map으로 구현했던 것 같습니다

(**사실 일치한 넘버/상금/일치한 로또를 구현하기에는 enum과 map을 동시에 쓰는 것이 가장 이상적이라고 생각하긴 했지만 구현하는데에 너무 어려움이
있어서 Map으로만 구현해보는 것을 우선적을 고려했던 것 같습니다.)

- 또, 돈을 받고->그에 대한 로또를 사고->수익률을 계산하는 과정에서 money라는 객체가 필요하다고 생각되어서 만들게 되었습니다.


## 🚀 3단계 - 로또 2등 당첨
로또 당첨 번호를 받아 일치한 번호 수에 따라 당첨 결과를 보여준다..


### 🤔 고민한 내용
- 당첨 통계를 내는 부분에서 5개 일치하고 보너스 볼이 일치할때 five_bonus라는 랭크를 추가하여 구현하였고,

기존 5개가 일치하는 부분이 존재하였기 때문에, 이부분을 입력받을때, 어떤 식으로 five와 five_bonus를 구현해야하는지에

대해 고민했습니다.

LottoResult를 받는 부분에 있어서, 5개 일치하는 경우, 보너스 볼이 일치하는지 검증하고, enum에 저장하는 형식을 택하게
되었습니다.

## 🚀 4단계 - 로또 수동 구매
로또 수동 번호 개수를 입력받고, 그 개수만큼 번호 6개를 입력해준다..


### 🤔 고민한 내용
- 기존의 lottoticket을 받는 부분을 자동적으로 생성되자마자 숫자를 부여받게 만들었기 때문에,

수동으로 어떻게 입력시켜야 할 지에 대한 고민이 있었습니다.

그 부분에 대해서는 lottoticket 에서는 6개 숫자만을 받도록 만들고 일급 컬렉션에서,

수동으로 받을 6개의 리스트와/ 자동으로 받을 6개의 리스트를 만드는 것을 구현하였습니다.
