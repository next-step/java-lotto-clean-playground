# 1. 로또 자동 구매

## 기능 요구사항

- [x] 로또 구입 금액을 입력받는다.
- [x] 로또 한 장의 가격은 1,000원이다.
- [x] 구입 금액을 기준으로 구매할 로또 개수를 계산한다.
- [x] 로또 한 장은 1부터 45까지의 숫자 중 서로 다른 6개의 숫자로 구성한다.
- [x] 생성된 로또 번호는 오름차순으로 정렬한다.
- [x] 구매한 로또 개수와 번호를 출력한다.

# 2. 로또 당첨

## 당첨 번호 입력

- [x] 지난주 당첨 번호 6개를 입력받는다.
- [x] 당첨 번호는 쉼표를 기준으로 구분한다.
- [x] 당첨 번호가 1부터 45 사이인지 확인한다.
- [x] 당첨 번호가 6개인지 확인한다.
- [x] 당첨 번호에 중복이 없는지 확인한다.

## 당첨 결과 계산

- [x] 구매한 로또와 당첨 번호를 비교한다.
- [x] 일치하는 번호의 개수를 계산한다.
- [x] 당첨 등수를 계산한다.

## 당첨 기준

- [x] 3개 일치: 5등 / 5,000원
- [x] 4개 일치: 4등 / 50,000원
- [x] 5개 일치: 3등 / 1,500,000원
- [x] 6개 일치: 1등 / 2,000,000,000원
- [x] 2개 이하 일치: 미당첨

## 당첨 통계

- [x] 각 등수의 당첨 개수를 계산한다.
- [x] 각 등수의 당첨 결과를 출력한다.
- [x] 전체 당첨 금액을 계산한다.
- [x] 구입 금액을 기준으로 총 수익률을 계산한다.
- [x] 총 수익률을 출력한다.

# 3. 로또 2등

## 보너스 번호

- [x] 2등 판정을 위한 보너스 번호를 입력받는다.
- [x] 보너스 번호가 숫자인지 확인한다.
- [x] 보너스 번호가 1부터 45 사이인지 확인한다.
- [x] 보너스 번호가 기존 당첨 번호와 중복되지 않는지 확인한다.

## 당첨 기준

- [x] 6개 일치: 1등
- [x] 5개 일치 + 보너스 번호 일치: 2등
- [x] 5개 일치 + 보너스 번호 불일치: 3등
- [x] 4개 일치: 4등
- [x] 3개 일치: 5등
- [x] 2개 이하 일치: 미당첨

## 당첨 결과

- [x] 1등부터 5등까지 당첨 결과를 계산한다.
- [x] 2등은 보너스 번호 일치 여부를 함께 확인한다.
- [x] 각 등수별 당첨 횟수를 출력한다.
- [x] 총 당첨 금액을 계산한다.
- [x] 총 수익률을 계산한다.

# 4. 로또 수동 구매

## 수동 구매 개수 입력

- [x] 수동으로 구매할 로또 개수를 입력받는다.
- [x] 수동 구매 개수가 숫자인지 확인한다.
- [x] 수동 구매 개수가 0 이상인지 확인한다.
- [x] 수동 구매 개수가 전체 구매 개수를 초과하지 않는지 확인한다.
- [x] 전체 구매 개수에서 수동 구매 개수를 제외하여 자동 구매 개수를 계산한다.

## 수동 로또 번호 입력

- [x] 수동 구매 개수만큼 로또 번호를 입력받는다.
- [x] 입력된 번호를 쉼표 기준으로 구분한다.
- [x] 로또 번호가 숫자인지 확인한다.
- [x] 로또 번호가 1부터 45 사이인지 확인한다.
- [x] 로또 번호가 6개인지 확인한다.
- [x] 로또 번호에 중복이 없는지 확인한다.
- [x] 입력된 로또 번호를 오름차순으로 정렬한다.

## 자동 로또 생성

- [x] 남은 구매 개수만큼 자동 로또를 생성한다.
- [x] 1부터 45 사이에서 서로 다른 숫자 6개를 생성한다.
- [x] 생성된 번호에 중복이 없도록 한다.
- [x] 생성된 번호를 오름차순으로 정렬한다.

## 구매 결과 출력

- [x] 수동 구매 개수와 자동 구매 개수를 출력한다.
- [x] 수동 로또를 먼저 출력한다.
- [x] 자동 로또를 수동 로또 다음에 출력한다.

# 5. 리팩터링

## 도메인 객체

- [x] `LottoNumber`가 하나의 로또 번호를 관리한다.
- [x] `LottoNumbers`가 로또 번호 컬렉션을 관리한다.
- [x] `Lotto`가 하나의 로또를 표현한다.
- [x] `Lottos`가 구매한 로또 목록을 관리한다.
- [x] `PurchaseAmount`가 구입 금액을 관리한다.
- [x] `WinningLotto`가 당첨 번호와 보너스 번호를 관리한다.
- [x] `WinningResult`가 당첨 결과를 관리한다.
- [x] `Rank` Enum이 당첨 등수와 상금을 관리한다.

## 객체 책임 분리

- [x] 로또 번호 범위 검증을 도메인 객체가 담당한다.
- [x] 로또 번호 개수 검증을 `LottoNumbers`가 담당한다.
- [x] 로또 번호 중복 검증을 `LottoNumbers`가 담당한다.
- [x] 입력, 출력, 도메인, 서비스의 역할을 분리한다.
- [x] 사용하지 않는 메서드와 생성자를 제거한다.
- [x] 불필요한 로또 번호 캐싱을 제거한다.
- [x] 중복된 로또 규칙을 한 곳에서 관리하도록 개선한다.

# 예외 처리

다음과 같은 잘못된 입력에는 `IllegalArgumentException`을 발생시킨다.

- [x] 구입 금액이 숫자가 아닌 경우
- [x] 구입 금액이 1,000원 미만인 경우
- [x] 구입 금액이 1,000원 단위가 아닌 경우
- [x] 로또 번호가 1부터 45 사이가 아닌 경우
- [x] 로또 번호가 6개가 아닌 경우
- [x] 로또 번호가 중복된 경우
- [x] 당첨 번호와 보너스 번호가 중복된 경우
- [x] 수동 구매 개수가 전체 구매 개수를 초과한 경우
- [x] 모든 예외 메시지는 `[ERROR]`로 시작한다.
