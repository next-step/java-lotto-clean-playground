## `ResultView`

### 구매 결과 출력 기능

- [x] 수동으로 구매한 로또 수를 출력한다.
- [x] 자동으로 구매한 로또 수를 출력한다.

### 로또 번호 출력 기능

- [x] `Lottos`로부터 전체 `Lotto` 목록을 가져온다.
- [x] 각 `Lotto`의 번호 목록을 출력 문자열로 변환한다.
- [x] 구매한 전체 로또 수만큼 로또 번호를 한 줄씩 출력한다.
- [x] 로또 번호 출력 후 빈 줄을 출력한다.

### 로또 출력 형식 생성 기능

- [x] 로또 번호 목록 앞에 여는 대괄호(`[` )를 추가한다.
- [x] 마지막 번호를 제외한 각 번호 뒤에 쉼표와 공백을 추가한다.
- [x] 마지막 번호 뒤에 닫는 대괄호(`]`)를 추가한다.
- [x] 완성된 로또 출력 문자열을 반환한다.
- [x] 전체 로또의 출력 문자열을 `List<String>`으로 반환한다.

### 당첨 통계 출력 기능

- [x] `"당첨 통계"`와 구분선을 출력한다.
- [x] 5등 당첨 결과를 출력한다.
- [x] 4등 당첨 결과를 출력한다.
- [x] 3등 당첨 결과를 출력한다.
- [x] 2등 당첨 결과를 출력한다.
- [x] 1등 당첨 결과를 출력한다.
- [x] 각 등수의 일치 개수, 당첨 금액, 당첨 개수를 출력한다.
- [x] 2등 결과에 `"보너스 볼 일치"` 문구를 포함한다.
- [x] 총 수익률을 출력한다.

### 등수별 출력 형식 생성 기능

- [x] 일반 등수의 출력 문자열을 생성한다.
- [x] 2등인 경우 보너스 볼 일치 문구가 포함된 출력 문자열을 생성한다.
- [x] `Map<Rank, Integer>`에서 해당 등수의 당첨 개수를 가져온다.

## `PurchasePrice`

### 구입 금액 관리 기능

- [x] 구입 금액을 저장한다.
- [x] 로또 한 장의 가격을 1,000원으로 관리한다.
- [x] 구입 금액을 이용해 구매 가능한 전체 로또 수를 계산한다.

### 구입 금액 검증 기능

- [x] 구입 금액이 양수인지 검증한다.
- [x] 구입 금액이 0 이하이면 `IllegalArgumentException`을 발생시킨다.
- [x] 구입 금액이 1,000원의 배수인지 검증한다.
- [x] 구입 금액이 1,000원의 배수가 아니면 `IllegalArgumentException`을 발생시킨다.

### 수동 로또 수 검증 기능

- [x] 수동 로또 수가 0 이상인지 검증한다.
- [x] 수동 로또 수가 음수이면 `IllegalArgumentException`을 발생시킨다.
- [x] 수동 로또 수가 구매 가능한 전체 로또 수를 초과하는지 검증한다.
- [x] 수동 로또 수가 구매 가능한 전체 로또 수를 초과하면 `IllegalArgumentException`을 발생시킨다.

### 자동·수동 로또 수 계산 기능

- [x] 수동 로또 수를 저장한다.
- [x] 전체 로또 수에서 수동 로또 수를 빼 자동 로또 수를 계산한다.
- [x] 수동 로또 수를 반환한다.
- [x] 자동 로또 수를 반환한다.

### 수익률 계산 기능

- [x] 총 당첨 금액을 구입 금액으로 나눈다.
- [x] 계산된 수익률을 `float`로 반환한다.

## `LottoNumber`

- [x] `compareTo()`를 재정의해 로또 번호의 정렬 기준을 제공한다.
- [x] `equals()`를 재정의해 번호 값이 같으면 같은 객체로 비교한다.
- [x] `hashCode()`를 재정의해 번호 값을 기준으로 해시값을 생성한다.

### 로또 번호 출력 기능

## `Rank`

### 당첨 등수 관리 기능

- [x] 1등을 `FIRST`로 관리한다.
- [x] 2등을 `SECOND`로 관리한다.
- [x] 3등을 `THIRD`로 관리한다.
- [x] 4등을 `FOURTH`로 관리한다.
- [x] 5등을 `FIFTH`로 관리한다.
- [x] 낙첨을 `MISS`로 관리한다.
- [x] 각 등수에 당첨 번호 일치 개수와 당첨 금액을 저장한다.

### 당첨 등수 판정 기능

- [x] 당첨 번호가 6개 일치하면 `FIRST`를 반환한다.
- [x] 당첨 번호가 5개 일치하고 보너스 볼이 일치하면 `SECOND`를 반환한다.
- [x] 당첨 번호가 5개 일치하면 `THIRD`를 반환한다.
- [x] 당첨 번호가 4개 일치하면 `FOURTH`를 반환한다.
- [x] 당첨 번호가 3개 일치하면 `FIFTH`를 반환한다.
