# 로또 - 클린 코드

## 기능 목록

- [ ] 구입 금액을 입력받는다.
- [ ] 숫자가 아닌 입력이면 예외를 발생시킨다.
- [ ] 구입 금액이 1000원 이상인지 검사한다.
- [ ] 구입 금액이 1000원 단위인지 검사한다.
- [ ] 구매 가능한 로또 개수를 계산한다.
- [ ] 구매 가능한 개수만큼 로또를 생성한다.
- [ ] 로또 번호를 오름차순으로 정렬한다.
- [ ] 생성된 로또를 화면에 출력한다.
- [ ] 당첨 번호를 입력받는다.
- [ ] 각 로또와 당첨 번호의 일치 개수를 계산한다.
- [ ] 일치 개수에 따라 당첨 등수를 계산한다.
- [ ] 등수별 당첨 개수를 계산한다.
- [ ] 총 당첨금을 계산한다.
- [ ] 수익률을 계산한다.

## 테스트 목록

### Lotto
- [x] 번호 개수 검증
- [x] 번호 범위 검증
- [x] 중복 번호 검증
- [x] matchCount 계산

### LottoStore
- [x] 구매 개수 계산
- [x] 구매 금액 검증

### LotteryStatistics
- [x] 당첨 통계 계산
- [x] 총 당첨금 계산

### Rank
- [x] 일치 개수에 따른 등수 반환
