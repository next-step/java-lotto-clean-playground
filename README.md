# 🎰 java-lotto

구입 금액만큼 로또를 자동 발급하고, 지난 주 당첨 번호와 비교해 당첨 통계와 수익률을 출력하는 콘솔 애플리케이션입니다.

## 📌 기능 목록

### 입력
- [x] 구입 금액을 입력받는다.
    - 숫자가 아니면 예외가 발생한다.
- [x] 지난 주 당첨 번호를 쉼표(`,`)로 구분해 입력받는다.
    - 숫자가 아닌 값이 있으면 예외가 발생한다.

### 로또 구매
- [x] 구입 금액에 맞는 개수만큼 로또를 발급한다. (1장 = 1,000원)
    - 금액이 1,000원 미만이면 예외가 발생한다.
    - 금액이 1,000원 단위가 아니면 예외가 발생한다.
- [x] 로또 1장은 1~45 사이의 중복되지 않는 숫자 6개로 이루어진다.
    - 번호가 `null`이면 예외가 발생한다.
    - 번호가 6개가 아니면 예외가 발생한다.
    - 중복된 번호가 있으면 예외가 발생한다.
    - 1~45 범위를 벗어나면 예외가 발생한다.
- [x] 자동 번호는 정렬된 상태로 생성된다.

### 당첨 확인
- [x] 구매한 로또와 당첨 번호를 비교해 일치 개수를 구한다.
- [x] 일치 개수에 따라 등수를 판단한다.

| 등수 | 일치 개수 | 당첨금 |
|:---:|:---:|---:|
| 1등 | 6개 | 2,000,000,000원 |
| 2등 | 5개 | 1,500,000원 |
| 3등 | 4개 | 50,000원 |
| 4등 | 3개 | 5,000원 |
| 꽝 | 0~2개 | 0원 |

### 출력
- [x] 구매한 로또 개수와 각 로또의 번호를 출력한다.
- [x] 등수별 당첨 개수를 출력한다.
- [x] 총 수익률(총 당첨금 ÷ 구입 금액)을 소수점 둘째 자리까지 출력한다.

## 💻 실행 예시

```
구입금액을 입력해 주세요.
14000
14개를 구매했습니다.
[8, 21, 23, 41, 42, 43]
[3, 5, 11, 16, 32, 38]
...
지난 주 당첨번호를 입력해 주세요.
1, 2, 3, 4, 5, 6
당첨 통계
---------
3개 일치 (5000원)- 1개
4개 일치 (50000원)- 0개
5개 일치 (1500000원)- 0개
6개 일치 (2000000000원)- 0개
총 수익률은 0.35입니다.
```

## 📂 Structure

```
java-lotto
├── build.gradle
├── settings.gradle
└── src
    ├── main/java
    │   ├── Application.java              # 프로그램 진입점, 전체 흐름 조립
    │   ├── domain
    │   │   ├── Lotto.java                # 로또 1장 (LottoNumber 6개의 일급 컬렉션)
    │   │   ├── LottoNumber.java          # 로또 번호 1개 (1~45 원시값 포장)
    │   │   ├── Lottos.java               # 구매한 로또 묶음, 등수별 개수 집계
    │   │   ├── LottoMachine.java         # 개수만큼 로또 발급
    │   │   ├── LottoResult.java          # 총 당첨금 · 수익률 계산
    │   │   ├── PurchaseAmount.java       # 구입 금액 (원시값 포장, 구매 개수 계산)
    │   │   └── Rank.java                 # 등수 enum (일치 개수 → 당첨금)
    │   ├── lottoGenerator
    │   │   ├── LottoGenerator.java       # 번호 생성 전략 인터페이스
    │   │   ├── RandomLottoGenerator.java # 1~45 중 무작위 6개 생성
    │   │   └── FixedLottoGenerator.java  # 고정 번호 반환 (테스트용)
    │   └── view
    │       ├── InputView.java            # 구입 금액 · 당첨 번호 입력
    │       └── ResultView.java           # 구매 내역 · 당첨 통계 출력
    └── test/java/domain
        ├── LottoMachineTest.java
        ├── LottosTest.java
        └── PurchaseAmountTest.java
```
