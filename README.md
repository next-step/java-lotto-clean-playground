## 🕹️ 로또

### 기능 구현 목록

#### 금액
- 구입한 금액은 0원을 초과한 금액이어야 한다.
- 구입한 금액이 1000원 단위여야 한다.

#### 로또 번호
- 오름차순 정렬이다.
- 중복되지 않는다.
- 1~45 사이의 숫자로 구성되어있다.

#### 로또
- 로또 번호를 발급해야 한다.
- 로또 1장의 가격은 1000원이다.

구입금액을 입력해 주세요.(1000원 단위)
