# 🎰로또🎰

## 프로젝트 개요

사용자가 구매 금액을 입력하면 수동으로 원하는 번호를 입력하거나 자동으로 번호를 생성하여 로또를 발행합니다. 당첨 번호 및 보너스 번호와 대조하여 당첨 통계와 수익률을 산출하는 자바 애플리케이션입니다.

---
## 기능 요구사항

1. 입력 및 데이터 검증
   - 구입 금액 입력 
     - 1,000원 단위의 양의 정수를 입력받습니다. (최소 1,000원)
   - 수동 구매 수량 입력 
     - 전체 구입 금액으로 살 수 있는 로또 개수를 초과할 수 없습니다. 
   - 수동 번호 / 당첨 번호 입력 
     - 쉼표(,)로 구분된 6개의 숫자를 입력받습니다. 
     - 검증: 1~45 범위 준수, 6개 숫자 구성, 숫자 간 중복 여부를 확인합니다. 
   - 보너스 번호 입력 
     - 당첨 번호 6개와 중복되지 않는 하나의 숫자를 입력받습니다.
   - 재시도 로직: 잘못된 입력 시 [ERROR] 메시지를 출력하고 해당 부분부터 다시 입력을 받습니다.

2. 로또 발행 및 당첨 로직
   - 혼합 발행: 사용자가 지정한 수량만큼 수동으로 로또를 생성하고, 나머지는 자동 생성합니다.
   - 당첨 순위 판별 
     - 1등: 6개 일치 
     - 2등: 5개 일치 + 보너스 번호 일치 
     - 3등: 5개 일치 
     - 4등: 4개 일치 
     - 5등: 3개 일치 
   - 수익률 계산 
     - 총 당첨 금액을 합산하여 구매 금액 대비 수익률을 산출합니다. 
     - 수익률은 소수점 둘째 자리에서 반올림하여 표현합니다.

3. 결과 출력 
   - 구매 현황: "수동으로 N장, 자동으로 M개를 구매했습니다."와 같이 상세 수량을 안내합니다. 
   - 당첨 통계: 등수별 일치 개수, 상금, 당첨 횟수를 출력합니다. (2등 보너스 일치 여부 별도 표시)
   - 수익률: 총 수익률을 출력하고, 기준(1) 대비 이득/손해 여부를 친절하게 안내합니다.

## 프로젝트 구조
```text
src/main/java/racingcar
├── controller
│   ├── Validator.java              # 입력 검증
│   └── LottoController.java        # 게임 흐름 제어
├── domain
│   ├── Lotto.java                  # 로또 단일 객체 (불변)
│   ├── Lottos.java                 # 로또 일급 컬렉션 (통계 산출 책임)
│   ├── LottoNumber.java            # 로또 번호 객체 (캐싱 및 검증)
│   └── LottoRank.java              # 당첨 등수 및 상금 정보 (Enum)
├── constant
│   └── ErrorMessage.java           # 에러 메시지 Enum
├── dto
│   ├── LottoStatistics.java        # 로또 번호 출력용 DTO
│   └── LottoStatus.java            # 당첨 통계 결과 전달용 DTO
├── view
│   ├── InputView.java              # 사용자 입력
│   └── OutputView.java             # 결과 출력
├── AppConfig.java                  # Application의 config 파일
└── Application.java                # 프로그램 시작점
```
