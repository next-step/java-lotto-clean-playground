# 로또 로또

## 기능 명세

### 로또 가맹점

* 로또 1장의 가격은 1000원이다.
* 로또 구입 금액을 입력하면 구입 금액에 해당하는 로또를 발급해야 한다.
* 구매한 후 남는 돈 (1000원 미만)은 거스름돈으로 돌려준다.

### 로또 메이커

* 임의의 6개의 로또 숫자를 뽑아서 로또를 만든다.
* 로또들끼리는(숫자 6개 조합끼리는) 중복되어도 된다.

### 로또

* 총 6개의 로또 숫자가 있다.
* 6개의 숫자가 겹치지 않는지 검증한다.

### 로또 숫자

* 숫자는 1~45 사이의 값이다.

### 로또 당첨 숫자

* 주어진 당첨 번호와 일치한 번호 수에 따라 결정한다.
  ```
  3개 일치 (5000원)
  4개 일치 (50000원)
  5개 일치 (1500000원)
  6개 일치 (2000000000원)
  ```

### 로또 당첨 정보

* 로또별로 로또 당첨된 개수를 파악한다.
* 일치하는 당첨개수별로 수를 센다.
* 수익률을 계산한다.
