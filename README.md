# 로또

## 기능 요구사항

- [x] 로또 구입 금액을 입력받는다.
- [x] 구입 금액에 해당하는 수량만큼 로또를 발급한다.
- [x] 로또 1장의 가격은 1000원이다.
- [x] 발급한 로또 수량을 출력한다.
- [x] 발급한 로또 번호를 출력한다.
- [x] 로또 번호는 오름차순으로 출력한다.

## 도메인 규칙

### LottoNumber

로또 번호 하나를 나타낸다.

- [x] 로또 번호는 1 이상 45 이하의 숫자만 가질 수 있다.
- [x] 같은 값을 가진 로또 번호는 같은 번호로 판단한다.

예외 상황

- 1보다 작은 숫자라면 예외가 발생한다.
- 45보다 큰 숫자라면 예외가 발생한다.

### Lotto

로또 번호 6개를 가진 로또 한 장을 나타낸다.

- [x] 로또는 6개의 번호를 가진다.
- [x] 로또 번호는 중복될 수 없다.
- [x] 로또 번호는 오름차순으로 정렬되어 관리된다.

예외 상황

- 로또 번호가 6개가 아니라면 예외가 발생한다.
- 중복된 로또 번호가 존재한다면 예외가 발생한다.

### RandomLottoGenerator

랜덤으로 로또 한 장을 생성한다.

- [x] 1부터 45까지의 숫자 중 6개를 뽑는다.
- [x] 생성된 번호로 로또 한 장을 만든다.

### InputView

사용자 입력을 담당한다.

- [x] 구입 금액을 입력받는다.
- [x] 입력값을 숫자로 변환한다.

예외 상황

- 숫자로 변환할 수 없는 값을 입력하면 예외가 발생한다.

### ResultView

출력을 담당한다.

- [x] 구매한 로또 수량을 출력한다.
- [x] 구매한 로또 번호 목록을 출력한다.
