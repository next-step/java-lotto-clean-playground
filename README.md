# 로또 미션

안녕하세요 민준님! 초록스터디 스터디원으로 참여하게 된 김동영입니다.

자바는 학교 강의에서만 사용해봤던 터라, 실제로 제약조건을 지켜가며 코딩하는 건 이번이 처음입니다 ㅠㅠ
저번 미션에서 일급 컬렉션이란 개념을 처음 알고 실제로 적용해봤습니다. 제약조건과 요구사항들을 하나씩 확인하면서 만들다 보니 이제 막 2단계를 마무리했습니다. 너무 뒤처지는 게 아닌가 걱정되네요.. 걱정은 있지만 항상 배우겠다는 생각으로 끝까지 해보겠습니다. 늦은 시간에 제출한 점 죄송합니다. 이번 미션 잘 부탁드리겠습니다!

> 구현보다 일단은 책임 분리와 역할을 나누는 것, 그리고 제약조건을 지키는 걸 우선시하다 보니 2단계까지만 수행했습니다.. 죄송해요..

## 어려웠던 점

### 1. 클래스의 책임과 역할 분리

아직 클래스에 책임과 역할을 적절하게 분리하는 게 어려웠습니다. 기능을 만들다 보면 결과적으로 depth도 넘어가 있었고, 하나의 클래스 안에 너무 많은 기능들이 있어 이후 분리하는 데 시간이 가장 오래 소요됐던 것 같습니다.

### 2. 자바의 기본적인 문법에 대한 학습 부족

컬렉션 프레임워크에 대한 기본적인 학습이 미흡했던 것 같습니다. 예를 들어 "배열에 해당 숫자들이 포함되어 있는가?" 같은 기능을 구현하기 위해 여러 개의 메서드 및 반복문을 통해서 만들다가, 구글링을 통해 컬렉션 프레임워크에서 제공하는 기능 중에 이미 존재한다는 걸 보고 "아직 문법도 잘 몰랐구나" 생각했습니다.
