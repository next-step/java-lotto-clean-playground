# java-lotto

## User Requirement

- 사용자는 로또 구입 금액을 입력한다.
- 입력한 금액만큼 로또가 발급된다. (1장 1,000원)
- 사용자는 원하는 수만큼 로또를 수동으로 직접 입력해 구매하고, 나머지는 자동으로 발급된다.
- 발급된 수동/자동 로또 장수와 각 로또의 번호가 출력된다. (번호 개수 6개, 번호 범위는 1~45)
- 사용자는 지난 주 당첨 번호와 보너스 볼을 입력한다.
- 구매한 각 로또가 당첨 번호와 몇 개 일치하는지(및 보너스 볼 일치 여부)에 따라 등수가 매겨진다.
- 등수별 당첨 개수와 총 수익률이 출력된다.

## System Requirement

#### 입력

- [x] 로또 구입 금액을 입력받는다.
- [x] 구입 금액을 로또 가격으로 나누어 구매 가능한 장수를 계산한다.
- [x] 수동으로 구매할 로또 수를 입력받는다.
- [x] 수동으로 구매할 번호를 수동 구매 수만큼 입력받는다.
- [x] 지난 주 당첨 번호를 쉼표(,)를 기준으로 분리하여 입력받는다.
  - [x] 분리한 각 당첨 번호의 앞뒤 공백을 제거한다.
- [x] 보너스 볼을 입력받는다.

#### 로또 생성

- [x] 로또 한 장은 서로 다른 6개의 번호를 가진다.
- [x] 로또 번호는 1부터 45 사이의 값이다.
- [x] 입력받은 수동 번호로 로또를 생성한다.
- [x] 남은 장수(전체 - 수동)만큼 자동으로 로또를 발급한다.

#### 당첨 판정

- [x] 구매한 로또가 당첨 번호와 일치하는 번호 수를 센다.
- [x] 구매한 로또가 보너스 볼을 포함하는지 확인한다.
- [x] 일치하는 번호 수(및 보너스 볼 일치 여부)에 따라 등수를 판정한다.
  - 0~2개 일치: 0원
  - 3개 일치: 5,000원 (5등)
  - 4개 일치: 50,000원 (4등)
  - 5개 일치: 1,500,000원 (3등)
  - 5개 일치 + 보너스 볼 일치: 30,000,000원 (2등)
  - 6개 일치: 2,000,000,000원 (1등)

#### 통계

- [x] 등수별 당첨 개수를 집계한다.
- [x] 총 수익률(총 상금 ÷ 구입 금액)을 계산한다.

#### 출력

- [x] 수동/자동으로 구매한 로또 장수를 출력한다.
- [x] 각 로또의 번호를 오름차순으로 출력한다.
- [x] 당첨 통계를 등수별 당첨 개수와 함께 출력한다.
- [x] 총 수익률을 소수점 둘째 자리까지 출력한다.
