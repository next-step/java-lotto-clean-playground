## 🕹️ 로또

### 기능 구현 목록

#### 금액

- 구입한 금액은 0원을 초과한 금액이어야 한다.
- 구입한 금액이 1000원 단위여야 한다.

#### 로또 번호

- 오름차순 정렬이다.
- 중복되지 않는다.
- 1~45 사이의 숫자로 구성되어있다.

#### 로또

- 로또 번호를 발급해야 한다.
- 로또 1장의 가격은 1000원이다.

#### 당첨 결과

- 지난 주 당첨 번호를 입력받는다.
- 당첨 통계를 보여준다.
    - 1등: 6개 일치 / 2_000_000_000원
    - 2등: 5개 일치 + 보너스 볼 / 30_000_000원
    - 3등: 5개 일치 / 1_500_000원
    - 4등: 4개 일치 / 50_000원
    - 5등: 3개 일치 / 5_000원

#### 수익률

- `(당첨 금액 / 구입 금액)`
- 소수점 둘째 자리까지만 보여준다.
- 만약, 1보다 작다면 `(기준이 1이기 때문에 결과적으로 손해라는 의미임)`라는 문구를 함께 보여준다.
