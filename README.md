# 자바-로또

## 기능 목록

### 로또 구매

- [x] 구입 금액에 해당하는 수만큼 로또를 구매한다.
- [x] 수동 구매 수를 입력받고, 수동 로또 번호를 입력받는다.
- [x] 수동 구매 수를 제외한 나머지 로또를 자동으로 생성한다.
- [x] 수동·자동 구매 수와 구매한 로또 번호를 출력한다.

### 로또 번호

- [x] 로또 번호는 1부터 45 사이의 값이다.
- [x] 로또 한 장은 중복되지 않는 6개의 번호를 가진다.
- [x] 자동 생성 로또 번호는 오름차순으로 정렬해 출력한다.

### 당첨 결과

- [x] 당첨 번호와 보너스 번호를 입력받는다.
- [x] 보너스 번호는 당첨 번호와 중복될 수 없다.
- [x] 일치한 번호 수와 보너스 번호 일치 여부로 등수를 판정한다.
- [x] 등수별 당첨 개수와 총 수익률을 출력한다.

## 입력 및 예외 정책

- 모든 입력의 앞뒤 공백을 제거한다.
- 숫자 형식이 아닌 값을 입력하면 예외 처리한다.
- 구입 금액은 1,000원 이상이며 1,000원 단위여야 한다.
- 수동 구매 수는 0 이상이고, 전체 구매 수를 초과할 수 없다.
- 당첨 번호와 수동 로또 번호는 쉼표(`,`)로 구분해 입력한다.
- 보너스 번호는 당첨 번호와 중복될 수 없다.
