# 로또

## 기능 요구사항
1. 로또 구입 금액을 입력하면 구입 금액에 해당하는 로또를 발급해야 한다.
    1. 로또 구입 금액을 입력한다.
        1. 숫자가 아니면 예외 처리한다.
        2. 1000원 미만이면 예외 처리한다.
    2. 로또 구입 금액을 1000원으로 나누어 로또 구매 장수를 구한다.
    3. 수동으로 구매할 로또 장수를 입력받는다.
        1. 숫자가 아니면 예외 처리한다.
        2. 0보다 작거나 구매 장수보다 크면 예외 처리한다.
    4. 수동 장수만큼 로또 번호를 입력받는다.
        1. 번호가 1~45 범위가 아니거나, 6개가 아니거나, 중복되면 예외 처리한다.
    5. 구매 장수에서 수동 장수를 뺀 만큼 자동 로또를 생성한다.
    6. 수동 장수, 자동 장수와 구매한 로또 번호를 출력한다. (수동 로또가 먼저 출력된다.)

2. 로또 당첨 번호를 받아 일치한 번호 수에 따라 당첨 결과를 보여준다.
    1. 로또 당첨 번호를 입력받는다.
    2. 보너스 볼을 입력받는다.
        1. 1~45 범위가 아니거나 당첨 번호와 중복되면 예외 처리한다.
    3. 각 로또의 당첨 번호 일치 개수와 보너스 볼 일치 여부로 등수를 판정한다.
        1. 5개 일치이고 보너스 볼이 일치하면 2등이다.
    4. 등수별 당첨 장수와 상금을 곱해 총 상금을 계산한다.
    5. 등수별 당첨 통계를 출력한다.
    6. 총 상금을 로또 구입 금액으로 나누어 수익률을 구한다.
    7. 소수점 셋째 자리에서 버림하여 수익률을 출력한다.
3. 잘못된 값을 입력하면 오류 메시지를 출력하고 해당 값을 다시 입력받는다.
