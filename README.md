# java-lotto

## User Requirement

- 사용자는 로또 구입 금액을 입력한다.
- 입력한 금액만큼 로또가 자동으로 발급된다. (1장 1,000원)
- 발급된 로또 장수와 각 로또의 번호가 출력된다. (번호 개수 6개, 번호 범위는 1~45)

## System Requirement

#### 입력

- [x] 로또 구입 금액을 입력받는다.
- [x] 구입 금액을 로또 가격으로 나누어 구매 가능한 장수를 계산한다.

#### 로또 생성

- [x] 로또 한 장은 서로 다른 6개의 번호를 가진다.
- [x] 로또 번호는 1부터 45 사이의 값이다.
- [x] 구매 장수만큼 로또를 발급한다.

#### 출력

- [x] 구매한 로또 장수를 출력한다.
- [x] 각 로또의 번호를 오름차순으로 출력한다.

## 추가로 생각해본 예외 처리 (개인 추가)

> 미션 요구사항에는 없지만, 실제 상황을 가정해 직접 떠올려 본 예외 케이스입니다.

- [x] 구입 금액이 숫자가 아닌 경우 예외를 발생시킨다.
- [x] 구입 금액이 0 이하인 경우 예외를 발생시킨다.
- [x] 구입 금액이 로또 가격 단위로 떨어지지 않는 경우 예외를 발생시킨다.
