# 로또

## 기능 목록

### 로또 구매

- [x] 로또 구입 금액을 입력받는다.
- [x] 로또 1장의 가격은 1000원이다.
- [x] 구입 금액에 해당하는 수량만큼 로또를 발급한다.
- [x] 구입 금액은 1000원 이상이어야 한다.
- [x] 발급한 로또 수량을 출력한다.
- [x] 발급한 로또 번호를 출력한다.

### 로또 생성

- [x] 로또 번호는 1 이상 45 이하의 숫자만 가질 수 있다.
- [x] 로또는 6개의 번호를 가진다.
- [x] 로또 번호는 중복될 수 없다.
- [x] 로또 번호는 오름차순으로 정렬되어 관리된다.
- [x] 랜덤으로 중복되지 않는 로또 번호 6개를 생성한다.

### 당첨 번호

- [x] 당첨 번호를 입력받는다.
- [x] 당첨 번호는 1 이상 45 이하의 숫자만 가질 수 있다.
- [x] 당첨 번호는 6개의 번호를 가진다.
- [x] 당첨 번호는 중복될 수 없다.
- [x] 보너스 번호를 입력받는다.
- [x] 보너스 번호는 1 이상 45 이하의 숫자만 가질 수 있다.
- [x] 보너스 번호는 당첨 번호와 중복될 수 없다.

### 당첨 결과

- [x] 구매한 로또와 당첨 번호를 비교한다.
- [x] 일치한 번호 수를 계산한다.
- [x] 5개 일치 시 보너스 번호 일치 여부에 따라 당첨 등급을 구분한다.
- [x] 일치한 번호 수에 따라 당첨 결과를 보여준다.
- [x] 당첨 결과에 따라 수익률을 계산하여 보여준다.

## 테스트 기준

### 로또 번호

- [x] 1보다 작은 로또 번호는 예외가 발생한다.
- [x] 45보다 큰 로또 번호는 예외가 발생한다.
- [x] 1 이상 45 이하의 로또 번호는 생성할 수 있다.
- [x] 같은 값을 가진 로또 번호는 같은 번호로 판단한다.
- [x] 서로 다른 값을 가진 로또 번호는 다른 번호로 판단한다.

### 로또

- [x] 로또 번호가 6개가 아니라면 예외가 발생한다.
- [x] 로또 번호가 6개라면 로또를 생성할 수 있다.
- [x] 중복된 로또 번호가 있다면 예외가 발생한다.

### 로또 구매

- [x] 구입 금액이 1000원보다 작으면 예외가 발생한다.
- [x] 구입 금액을 로또 가격으로 나누어 구매 수량을 계산한다.
- [x] 구입 금액에 해당하는 수량만큼 로또를 발급한다.

### 로또 자동 생성

- [x] 번호 6개를 가진 로또를 생성한다.

### 당첨 번호

- [x] 당첨 번호가 6개가 아니라면 예외가 발생한다.
- [x] 당첨 번호에 중복된 번호가 있다면 예외가 발생한다.
- [x] 당첨 번호의 각 번호는 1 이상 45 이하이다.
- [x] 보너스 번호가 당첨 번호와 중복되면 예외가 발생한다.
- [x] 구매 로또가 보너스 번호를 포함하는지 확인한다.

### 당첨 결과

- [x] 구매한 로또와 당첨 번호의 일치 개수를 계산한다.
- [x] 일치한 번호 수에 따라 당첨 결과를 계산한다.
- [x] 5개 일치에서는 보너스 번호 일치 여부에 따라 당첨 등급을 구분한다.
- [x] 구매 로또들의 당첨 등급별 개수를 계산한다.
- [x] 총 당첨금을 구입 금액으로 나누어 수익률을 계산한다.
