1단계 - 로또 자동 구매
--

기능 요구사항

- 로또 구입 금액을 입력하면 구입 금액에 해당하는 로또를 발급해야 한다.
- 로또 1장의 가격은 1000원이다.

필요한 객체

- 로또
- 로또 판매 기계
- 입출력
- 랜덤 번호 생성 객체

고민한 점
구입금액을 로또 가격 단위로 쪼갤 수 있는 파싱 객체가 필요함
해당 객체는 로또 가격을 파라미터로 받아서 개수를 반환해야함

출력 객체는 로또 번호를 String.join을 통해 리스트 형태로 출력해야함 
(toString 오버라이딩도 괜찮을듯) -> 로또 객체 내부에서 하는건데, 로또 객체가 해당 출력 책임이 있을지 고민

1~45까지 랜덤 번호를 생성하는 객체
- 중복 없이 생성해야함
- 6자리 생성해야함
- 정렬해서 반환?
