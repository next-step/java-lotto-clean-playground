# 로또 - 클린 코드

## 1단계 요구사항
- 로또
  - 6개의 중복되지 않은 숫자로 이루어져있다.
  - 각 숫자는 1~45 이다.
- 로또 숫자 생성기
  - 1~45 의 숫자를 생성한다.
  - 6개의 숫자를 생성한다.
- 로또 구입 금액을 입력하면 구입 금액에 해당하는 로또를 발급해야 한다.
- 로또 1장의 가격은 1000원이다.
- 로또 출력 시 오름차순으로 정렬해서 출력한다.

## 프로그래밍 요구사항

- 배열 대신 컬렉션을 사용한다.
- 줄여 쓰지 않는다(축약 금지).
- 함수(또는 메서드)의 길이가 10라인을 넘어가지 않도록 구현한다. 
  - 함수(또는 메서드)가 한 가지 일만 하도록 최대한 작게 만들어라.
