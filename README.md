# 로또 - 클린 코드

## 기능 목록

- [ ] 구입 금액을 입력받는다.
- [ ] 숫자가 아닌 입력이면 예외를 발생시킨다.
- [ ] 구입 금액이 1000원 이상인지 검사한다.
- [ ] 구입 금액이 1000원 단위인지 검사한다.
- [ ] 구매 가능한 로또 개수를 계산한다.
- [ ] 구매 가능한 개수만큼 로또를 생성한다.
- [ ] 로또 번호를 오름차순으로 정렬한다.
- [ ] 생성된 로또를 화면에 출력한다.


## 테스트 목록

### 1. Lotto
- [x] 번호가 6개이면 생성된다.
- [x] 번호가 6개보다 적으면 예외가 발생한다.
- [x] 번호가 6개보다 많으면 예외가 발생한다.
- [x] 번호가 45(최대값)를 포함해도 생성된다.
- [x] 번호가 0(최소값 미만)이면 예외가 발생한다.
- [x] 번호가 46(최대값 초과)이면 예외가 발생한다.
- [x] 중복 번호가 존재하면 예외가 발생한다.

### 2. LottoStore
- [x] 구매금액이 정확히 1000원이면 로또 1장이 생성된다.
- [x] 구매금액만큼 로또를 생성한다.
- [x] 구매금액이 1000원 단위가 아니면 예외가 발생한다.
- [x] 구매금액이 1000원보다 적으면 예외가 발생한다.
