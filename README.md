# 🎰로또🎰

## 프로젝트 개요

사용자가 구매한 금액만큼 로또 번호를 자동으로 발행하고, 당첨 번호와 대조하여 당첨 통계 및 수익률을 산출하는 자바 애플리케이션입니다.

---
## 기능 요구사항

1. 입력 및 데이터 검증
   - 로또 구입 금액 입력
     - 1,000원 단위의 금액을 숫자로 입력받습니다.
     - 예외 처리: 숫자가 아니거나, 1,000원 미만이거나, 1,000원으로 나누어 떨어지지 않는 경우 에러 메시지를 출력합니다. 
   - 당첨 번호 입력 
     - 쉼표(,)로 구분된 6개의 숫자를 입력받습니다. 
     - 예외 처리: 숫자가 1~45 범위를 벗어나는 경우, 개수가 6개가 아닌 경우, 중복된 숫자가 있는 경우 에러 메시지를 출력합니다.

2. 로또 발행 및 당첨 로직
   - 로또 자동 생성
     - 구매 금액에 맞는 수량만큼 로또를 발행합니다. 
     - 각 로또는 중복 없는 랜덤 숫자 6개를 가집니다. 
     - 정렬: 출력 시 사용자가 보기 편하도록 모든 로또 번호는 오름차순으로 정렬하여 저장합니다.
   - 당첨 순위 판별 
     - 발행된 로또와 당첨 번호를 비교하여 일치하는 숫자의 개수를 세고 순위를 결정합니다. 
   - 수익률 계산 
     - 총 당첨 금액을 합산하여 구매 금액 대비 수익률을 산출합니다. 
     - 수익률은 소수점 둘째 자리에서 반올림하여 표현합니다.

3. 결과 출력
   - 구매 수량 및 로또 번호 출력 
     - 발행된 로또의 개수와 각 로또의 번호를 한 줄씩 출력합니다. 
   - 당첨 통계 상세 출력 
     - 3개 일치(5등)부터 6개 일치(1등)까지 각 등수별 당첨 횟수를 출력합니다. 
   - 최종 수익률 안내

## 프로젝트 구조
```text
src/main/java/racingcar
├── controller
│   ├── Validator.java              # 입력 검증
│   └── LottoController.java        # 게임 흐름 제어
├── model
│   ├── Lotto.java                  # 로또 도메인 모델
│   ├── Lottos.java                 # 여러 로또를 처리하는 리스트 모델
│   ├── LottoRank.java              # 로또 리스트 모델
│   └── LottoNumberGenerator.java   # 로또 자동 발행 기능
├── constant
│   └── ErrorMessage.java           # 에러 메시지 Enum
├── view
│   ├── InputView.java              # 사용자 입력
│   └── OutputView.java             # 결과 출력
└── Application.java                # 프로그램 시작점
```
