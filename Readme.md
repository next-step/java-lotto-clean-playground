java-lotto
================

## 1. 요구사항
### 로또 자동 구매 (1단계)
- 구입 금액을 입력하면, 금액에 해당하는 로또를 발행한다.
- 로또 1장의 가격은 1000원이다.
- 발행된 로또 번호 6개는 1~45 범위이며 중복이 없어야 한다.
- 발행된 로또 번호는 오름차순으로 출력한다.

### 1.2 로또 당첨 결과
- 지난 주 당첨 번호 6개를 입력받는다.
- 각 로또와 당첨 번호를 비교하여 일치 개수를 계산한다.
- 일치 개수에 따라 당첨 결과를 집계하여 출력한다.
    - 3개 일치: 5,000원
    - 4개 일치: 50,000원
    - 5개 일치: 1,500,000원
    - 6개 일치: 2,000,000,000원
- 총 당첨금과 수익률을 계산하여 출력한다.
- 수익률 = 총당첨금 / 구입금액

### 1.3 2등(보너스) 당첨
- 보너스 번호 1개를 추가로 입력받는다.
- 2등 조건: 당첨 번호 5개 + 보너스 번호 일치
- 기존 5등(5개 일치)과 구분하여 집계한다.
- 5개 일치(보너스 X): 1,500,000원
- 5개 일치 + 보너스(2등): 30,000,000원

### 1.4 로또 수동 구매
- 자동 생성 기능은 유지한다.
- 사용자가 수동으로 구매할 로또 수를 입력할 수 있다.
- 사용자가 입력한 번호로 수동 로또를 생성할 수 있어야 한다.
- 입력값: 구입금액 → 수동 구매 수 → 수동 번호들 → 당첨번호 → 보너스
- 출력: 수동/자동 구매 수, 전체 티켓 목록, 당첨 통계 및 수익률

## 2. 클래스 구성
- LottoNumber: 로또 번호 1개
- Lotto: 로또 번호 6개의 묶음
- LottoTicket: 로또 한 장
- WinningNumbers: 당첨 번호(6개) + 보너스 번호(1개) 묶음
- Rank: 일치 개수와 보너스 여부로 등수를 결정하고 상금 결정
- Money: 구입 금액 값 객체
- LottoGenerator: 자동 로또 티켓 생성기
- LottoResult: 결과 집계

## 3. 예외사항
### 3.1 Money
- 구입금액이 1000원 미만이면 예외
- 구입금액이 1000원 단위가 아니면 예외
### 3.2 LottoNumber
- 로또 번호가 1~45 범위를 벗어나면 예외
### 3.3 Lotto
- 로또 번호가 6개가 아니면 예외
- 로또 번호가 중복이면 예외
### 3.4 WinningNumbers
- 보너스 번호가 당첨 번호 6개와 중복이면 예외. 범위 검증은 LottoNumber가 함.
### 3.5 InputView
- 수동 구매 수가 0 미만이면 예외
- 구매 수가 전체 구매 수를 초과하면 예외

## 4. 고민사항
처음엔 WinningNumbers, LottoTicket 같은 곳에서도 범위/중복 검증을 하다 보니 같은 검증 로직을 어디다 두어야하는 지에 대한 고민이 있었습니다. <br>
LottoNubmer에는 1~45까지의 범위를 두었고, Lotto에는 6개인지와 중복여부를 검증하도록 구성하였습니다.<br>
WinningNumbers에서는 1~45까지의 범위는 LottoNumber에서 검증오고, 보너스 번호가 생겼을때는 중복 번호를 추가적으로 검증하도록 하였습니다.
