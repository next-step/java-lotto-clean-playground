# 로또
기능
1. 순서 상관없이 1~45 숫자 6개
2. 1등 : 보너스 번호 없이 전부 한 줄에 일반 숫자 6개 맞춘다  
    2등: 일반 숫자 5개+보너스 번호  
    3등 : 일반 숫자 5개  
    4등 : 4개  
    5등 : 3개  
    그 외 : 꽝  

## 1단계-로또 자동 구매
기능 요구사항
1. 로또 1장의 가격은 1000원
2. 배열 대신 컬렉션 사용
3. 축약 금지
4. 함수 10라인 넘어가지 않는다

## 2단계-로또 당첨
기능 요구사항
1. 모든 원시 값과 문자열을 포장한다
2. 일급 컬렉션을 쓴다
