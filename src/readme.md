# 로또 자동 구매 요구사항

## 구입 금액
- [x] 로또 구입 금액을 입력하면 해당하는 로또 발급
    - [x] 1장 가격은 1000원
    - [x] 구입 금액은 1000원 단위여야 한다
    - [x] 구입 금액은 1000원 이상의 양수여야 한다
    - [ ] 구입 금액에 숫자가 아닌 값이 입력되면 예외 처리한다
    - [ ] 예외 발생 시 재입력을 받는다

## 로또 발급
- [x] 1부터 45까지 한 장에 6개 숫자
- [x] 한 로또에 중복되는 숫자가 없어야 한다
- [x] 로또 번호는 오름차순으로 정렬된다

## 당첨 번호
- [x] 로또 당첨 번호를 입력받는다
    - [x] 당첨 번호는 6개여야 한다
    - [x] 당첨 번호는 1~45 사이의 숫자여야 한다
    - [x] 당첨 번호에 중복된 숫자가 없어야 한다
    - [ ] 당첨 번호에 숫자가 아닌 값이 입력되면 예외 처리한다
    - [ ] 예외 발생 시 재입력을 받는다

## 당첨 결과
- [x] 일치한 번호 수에 따라 당첨 결과를 보여준다
    - [x] 3개 일치 - 5,000원
    - [x] 4개 일치 - 50,000원
    - [x] 5개 일치 - 1,500,000원
    - [x] 6개 일치 - 2,000,000,000원
- [x] 총 수익률을 계산하여 출력한다

# TASKS
- [x] 일급컬렉션으로 리팩토링
- [x] 모든 원시값과 문자열 포장
- [ ] 테스트 코드 작성
- [x] 예외 처리
- [ ] 미완성 예외 처리 보완 (숫자 아닌 값 입력, 재입력 유도)
